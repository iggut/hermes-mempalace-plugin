# MemPalace v3.5.0 Compatibility Check

**Date:** 2026-07-05
**Library version:** 3.3.6 → 3.5.0 (300 commits)
**Plugin version:** 1.6.0 → 1.7.0
**Result:** ✅ All compatible after fixes

## Breaking Changes Found and Fixed

### 1. `entity_detector.detect_entities` signature change
- **Old (3.3.6):** `detect_entities(text: str, languages=("en",)) -> dict`
- **New (3.5.0):** `detect_entities(file_paths: list, max_files=10, languages=("en",), corpus_origin=None) -> dict`
- **Fix:** Plugin now imports `extract_candidates` + `classify_entity` directly and builds a text-based detection pipeline in `tool_detect_entities()`. This is the same pipeline `detect_entities` uses internally after reading files.

### 2. Package shadowing in standalone test mode
- **Problem:** When `/home/iggut/.hermes/plugins` is on `sys.path` alongside the library directory, Python resolves `import mempalace` to the plugin package (which is also named `mempalace`), not the library.
- **Fix:** `_ensure_imported()` now temporarily removes the plugins directory from `sys.path` and evicts cached `mempalace.*` modules during library import, then restores them.

## New v3.5.0 Features Bridged

- **`mempalace_list_hallways`** — List within-wing hallway records with Hebbian strength
- **`mempalace_delete_hallway`** — Delete a hallway by ID
