## Module structure test fixes (v1.4)
When tests fail due to the modular refactor, common fixes:

1. **`api._searcher` → `api._search_memories_fn`** (test sets fake via this name)
2. **`api._miner` → `api._miner_add_drawer_fn`** (test sets fake via this name)
3. **`MemPalaceAPI.__init__` takes `config=` kwarg, not direct params**
4. **`lexical_scan_limit` on config, not on API constructor**
5. **Provider `prefetch()` early-exits if `not _initialized` — tests must set `provider._initialized = True`**
6. **`_ensure_api()` overwrites `_mp_api` — tests must `monkeypatch.setattr(provider, '_ensure_api', lambda: None)`**
7. **HolographicMirror: check `sys.modules['mempalace_plugin.provider']` not `hasattr(mod, 'HolographicMirror')`**
8. **Config schema uses dot-notation: `'retrieval.enabled'` not `'retrieval_mode'`**
9. **`sync_turn()` uses `_retrieval` when `retrieval_enabled=True`; to test via `_mp_api` directly, set `retrieval_enabled=False`**
10. **L2 tests: `provider._retrieval` is a `MemPalaceRetrieval` object — cannot import directly (not a package). Use config assertions or test the provider's `prefetch()` with properly-configured `_mp_api`.**
